# ⚔️ 1분 던전

**「죽을수록 강해진다.」**

모바일 브라우저에서 바로 즐기는 1~3분짜리 던전 크롤러 웹게임입니다.
회원가입, 서버, DB 없이 순수 HTML/CSS/JavaScript만으로 동작하며,
GitHub 저장소에 올리고 Pages만 켜면 누구나 바로 플레이할 수 있습니다.

## 게임 소개

작은 용사가 되어 10개의 방으로 이루어진 던전을 탐험합니다.
방마다 전투, 보물, 회복, 랜덤 이벤트 중 하나가 등장하고,
10번째 방에서는 강력한 보스가 기다립니다.

던전에서 죽거나 보스를 쓰러뜨리면 한 판이 끝나고,
그동안 모은 골드로 **영구 업그레이드**를 해서 다음 판을 더 유리하게 시작할 수 있습니다.

## 조작 방법

- **던전 입장**: 타이틀 화면에서 버튼을 눌러 던전에 입장합니다.
- **⚔️ 공격**: 현재 방의 적을 공격합니다. 확률적으로 치명타(1.8배 피해)가 터집니다.
- **🧪 회복**: 소지한 물약으로 최대 HP의 25%를 회복합니다. (기본 1개 보유)
- **🏃 도망**: 일반/강한 전투에서만 사용 가능하며, 60% 확률로 성공합니다. 전투당 2회까지만 시도할 수 있고, 성공해도 등을 스치는 이탈 피해를 약간 입습니다. 보스전에서는 사용할 수 없습니다.
- **이벤트/보물/회복 방**: 화면에 나타나는 선택지를 눌러 진행합니다.
- **🎒 인벤토리 / 🛒 상점 / 📖 도감**: 타이틀 화면 하단 버튼으로 진입해 장비를 관리하거나 구매하고, 지금까지 만난 몬스터를 확인할 수 있습니다.
- 모든 버튼은 손가락으로 누르기 쉽도록 48px 이상 크기로 제작되었습니다.

## 주요 기능

- **10개의 방 + 보스**: 일반 전투(50%) · 강한 전투(20%) · 보물(10%) · 회복(10%) · 이벤트(10%) 중 랜덤 등장, 10번째 방은 항상 보스
- **8종의 몬스터**: 거대 쥐 · 고블린 · 동굴 박쥐 · 해골 전사 · 좀비 · 독거미 · 오크 · 지옥의 기사. 회피, 방어, 재생, 강타, 치명타는 물론 🧪중독 · 🔥화상 · 💫기절 같은 상태이상 스킬도 몬스터마다 다르게 보유
- **3종의 보스**: 고대 드래곤(자가 회복 + 강공격 + 화상) · 마왕의 기사(방어 강화 + 강공격 + 기절) · 죽음의 군주(치명타 + 🧊빙결), 각자 고유한 전투 패턴으로 일반 몬스터보다 훨씬 위협적입니다
- **SD(데포르메)풍 캐릭터 아트**: 용사 · 몬스터 8종 · 보스 3종 전부 외부 이미지 없이 인라인 SVG로 직접 그려서, 어떤 환경에서도 추가 리소스 로딩 없이 즉시 표시됩니다.
- **장비 시스템**: 무기 · 갑옷 · 반지 3슬롯, 일반~전설 5등급, 던전에서 획득하며 자동으로 더 좋은 장비로 교체
- **🌟 레전더리 무기**: 보스를 처치하면 낮은 확률(12%)로 고유 특수효과가 있는 전설급 무기를 얻을 수 있습니다. 흡혈검 '카르페인'(피해량의 15% 흡수), 처형자의 도끼 '단두대'(적 HP 25% 이하일 때 추가 피해), 폭풍의 쌍검 '질풍'(추가 타격 확률) 3종이 있습니다.
- **🪙 골드 채굴 클리커**: 타이틀 화면의 동전을 탭하면 소량의 골드를 즉시 얻을 수 있습니다. 오토클리커 방지를 위해 분당 클릭 횟수 제한과, 기계적으로 일정한 간격의 클릭을 감지해 일시적으로 차단하는 로직이 들어있습니다.
- **👑 미니보스**: 5번째 방에는 최종 보스보다는 약하지만 일반 몬스터보다 강한 미니보스가 고정으로 등장합니다.
- **🔁 자동 전투**: 전투 중 자동전투를 켜면 스스로 공격하고, HP가 위험해지면 자동으로 물약을 쓰거나 안전하게 멈춥니다.
- **📜 전투 기록**: 지나간 전투 로그를 다시 스크롤해서 확인할 수 있습니다.
- **🏆 개인 최고 기록**: 던전 클리어 시간의 개인 최고 기록이 저장되어, 신기록을 세우면 알려줍니다.
- **🎒 인벤토리**: 보유한 모든 장비를 슬롯별로 확인하고, 탭 한 번으로 장착/해제할 수 있습니다.
- **🗒️ 일일 퀘스트**: 매일 새로운 퀘스트 3개가 주어집니다 (몬스터 처치, 방 통과, 보물방 방문, 유물 선택, 보스 처치, 던전 클리어 등). 목표를 달성하면 골드 보상을 받을 수 있습니다.
- **🛒 상점**: 골드로 장비와 전투를 도와주는 **동료(펫)**를 구매할 수 있습니다. 진열된 상품은 화면을 나갔다 들어와도 그대로 유지되며, 던전을 한 판 다녀오면 새로 재입고됩니다.
- **🐾 펫 강화**: 보유한 펫은 골드로 최대 Lv.10까지 강화할 수 있으며, 레벨이 오를수록 전투마다 추가로 주는 자동 피해가 늘어납니다.
- **📖 몬스터 도감**: 던전에서 처치한 몬스터만 해금되어 초상화 · 스탯 · 특수 능력이 공개됩니다. 도감을 모두 채우면 골드 획득량이 영구적으로 늘어납니다.
- **성장형 난이도**: 던전을 클리어할수록 몬스터도 함께 강해져서, 업그레이드로 공격력이 아무리 높아져도 일방적으로 전투가 쉬워지지 않습니다.
- **🏅 업적**: "물약 없이 클리어", "박물학자(도감 완성)" 등 6가지 업적을 달성하면 보너스 골드를 받습니다.
- **🔮 유물 선택**: 4번째, 7번째 방에서 이번 던전에만 적용되는 유물(장단점이 있는 특성) 하나를 선택합니다.
- **💥 콤보 & 필살기**: 공격을 5회 연속 적중시키면 필살기를 사용해 큰 피해를 줄 수 있습니다.
- **✨ 황금 몬스터**: 낮은 확률로 골드를 3배 주는 황금빛 몬스터가 등장합니다.
- **😈 매복 방**: 몬스터 두 마리가 연속으로 나타나는 위험한 방입니다.
- **☠️ 하드코어 모드**: 타이틀 화면에서 켤 수 있으며, 켠 상태로 죽으면 모든 기록이 초기화되는 대신 더 짜릿한 긴장감을 즐길 수 있습니다.
- **🃏 카드 뽑기**: 방에 따라 카드뽑기가 등장하며, 뽑기 전에 각 결과의 확률을 미리 확인할 수 있습니다.
- **🧩 장비 세트 효과**: 무기·갑옷·반지를 같은 등급으로 맞춰 장착하면 추가 스탯 보너스가 붙습니다.
- **🔗 유물 조합 시너지**: 4번째·7번째 방에서 특정 유물 조합을 함께 선택하면 시너지 효과가 발동합니다.
- **💀 엘리트 몬스터**: 낮은 확률로 등장하는 강화 몬스터로, 처치 시 장비가 확정으로 드롭됩니다.
- **🎯 헌터 챌린지**: 특정 몬스터를 일정 마리 수 처치하면 골드 보상을 받을 수 있으며, 진행도는 도감에서 확인할 수 있습니다.
- **🧙 방랑 상인**: 이벤트로 등장하며, 골드를 내고 무기 등급 강화를 시도할 수 있습니다.
- **📖 분기 스토리**: 던전 곳곳의 선택이 이어져, 보스전에 영향을 주는 스토리 전개를 경험할 수 있습니다.
- **🎁 웰컴백 보상**: 오랜만에 접속하면 그동안의 보상을 모아 지급받습니다.
- **랜덤 이벤트**: 상인, 제단, 요정 등 선택에 따라 결과가 달라지는 이벤트
- **영구 업그레이드**: 공격력 · 방어력 · 최대 HP · 골드 획득량 · 행운(치명타 확률) 5종, 레벨이 오를수록 비용 2배 증가
- **localStorage 저장**: 최고 도달 층, 총 골드, 플레이/클리어 횟수, 업그레이드 레벨, 보유 장비, 몬스터 도감 진행도가 영구 저장됩니다
- **진행 중 자동 저장**: 새로고침해도 진행 중이던 던전이 복원됩니다 (결과 화면 도달 시 초기화)
- **애니메이션 & 이펙트**: 피격 흔들림, 데미지 숫자 표시, 치명타 화면 플래시, 보스 등장 연출, 골드/보물 스파클, 회복 시 초록 플래시, HP 30% 이하일 때 붉은 비네트 경고, 화면 전환 페이드, 던전풍 코너 프레임과 횃불 조명 배경, 클리어 시 컨페티, 게임오버 시 균열 연출 등
- **배경음악(BGM)**: 외부 음원 없이 Web Audio API로 직접 만든 절차적 루프 음악. 타이틀 · 던전 탐험 · 전투 · 보스전마다 다른 테마가 자동으로 전환됩니다.
- **효과음**: 공격음 · 피격음 · 치명타음 · 골드 획득음 · 버튼음 · 보스 등장음 · 클리어음도 함께 합성되며, 타이틀 화면 우측 상단 아이콘으로 BGM/효과음을 한 번에 ON/OFF할 수 있습니다.
- **안전한 저장 데이터 처리**: 저장 데이터가 없거나 손상된 경우 기본값으로 자동 초기화

## 실행 방법

별도 빌드나 서버 설치 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## GitHub Pages 배포 방법

1. `index.html`, `style.css`, `game.js`, `README.md`를 GitHub 저장소에 푸시합니다.
2. 저장소 **Settings → Pages → Branch**에서 배포할 브랜치(예: `main`)와 루트 폴더를 선택합니다.
3. 발급된 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 바로 플레이할 수 있습니다.
4. 모든 리소스 경로가 상대 경로이므로 저장소 하위 경로에 배포해도 정상 동작합니다.

## 프로젝트 구조

```
/
├── index.html   # 화면 구조 (시작 / 게임 / 게임오버 / 클리어 / 업그레이드)
├── style.css    # 모바일 다크 판타지 테마 + 애니메이션
├── game.js      # 게임 데이터, 저장, 사운드, 전투, 던전 진행 로직
└── README.md
```
