# 성장 단계별 클래스 밸런스 보고서

검증일: 2026-09-25. 이 문서의 클리어율은 고정 규칙 시뮬레이션 결과이며 인간 플레이어의 성공률 추정치가 아니다.

## 적용한 변경

| 클래스 | 변경 | 의도 |
|---|---|---|
| 전사 | 방패 강타의 피해 감소 50% → 40% | 공격과 방어를 동시에 수행하는 이점 조정 |
| 도적 | HP 88 → 98, 방어 1 → 2, 맹독 쌍검 140% → 170% | 초반 생존력 보완, 공격력 성장의 스킬 효율 개선 |
| 마법사 | HP 84 → 90, 방어 1 → 2 | 스킬 중심 전투의 정체성을 유지하며 초반 생존력 보완 |

일반 방어의 피해 감소 75%, 독/화상, 치명타, 자원 비용, 유물, 장비, 적 수치, 난도 배율, 강화 비용과 상한은 유지했다. 스킬 배율과 전사 스킬의 감소율은 CLASSES 데이터에 모아 계산과 표시 수치를 확인하기 쉽게 했다. 기존 세이브 형식은 유지한다. 이전 탐험의 현재 HP는 임의로 채우지 않으며 이후 행동 계산에는 새 클래스 수치를 적용한다.

## 측정 조건

| 단계 | 공격/HP/방어/치명/골드/선제필살 레벨 | 강화 비용 합계 | 시작 장비 |
|---|---|---:|---|
| 초기 | 0/0/0/0/0/0 | 0 G | 없음 |
| 초반 | 2/2/1/1/0/0 | 430 G | iron, plate |
| 중반 | 5/5/3/4/2/1 | 2,810 G | fang, dusk, seal |
| 후반 | 10/10/6/10/5/1 | 19,005 G | star, dusk, crown |
| 최대 | 15/15/8/15/10/1 | 116,123 G | star, dusk, crown |

성장 단계는 실제 플레이 횟수 대신 동일한 강화 투자와 시작 장비로 정의한다. 장비는 모든 클래스에 동일하게 지급하며 비용 합계는 강화에만 해당한다. 장비 획득 비용/시간은 포함하지 않는다.

- 5단계 × 난도 4개 × 전략 2개 × 클래스 3개 × 200시드 = 조건군당 24,000회.
- 시드 1~200: 안전 우선, 정예 우선, 시작 장비 없음(안전 우선)의 전후 비교 144,000회.
- 조정에 쓰지 않은 시드 1001~1200: 안전 우선·정예 우선 전후 비교 96,000회. 합계 240,000회(후보 탐색 및 테스트 제외).
- 공격 위주: HP 40% 미만이면 물약, 그 외 일반 공격. 전술: 강타/화염 폭풍 방어를 최우선으로 하며, 물약이 불필요하고 적이 방패 태세가 아니면 자원이 충분할 때 스킬.
- 두 전략 모두 안전 경로는 쉼터/보물 우선, 정예 경로는 정예/전투 우선. 유물은 월광의 잔 우선, 없으면 첫 후보. 쉼터는 회복, 제단/상점은 지나친다.
- 시작 장비 없음은 시작 시 장비만 제거한다. 탐험 중 장비 획득과 자동 장착은 그대로 작동한다.
- 같은 입력 시드로 지도 생성은 일치하지만 전투 중 난수 소비가 달라 후속 적/장비/유물 선택은 달라질 수 있다. 결과는 고정 정책들의 비교이며 최적 전략 탐색이 아니다.

## 성장 보상과 남은 한계

일반 방어와 자원 관리의 가치는 유지된다. 초반 성장·최고 난도 안전 경로의 공격 위주 전략은 시드 1~200에서 세 클래스 모두 0%였으며 전술 전략은 98~99.5%였다. 중반 안전 경로의 승리 탐험 평균 전투 턴은 전사 20.12, 도적 17.78, 마법사 15.77이다. 전사는 생존, 도적은 치명/독, 마법사는 스킬 화력의 차이를 유지한다.

무성장 최고 난도, 초반 정예 연속 경로에는 전사의 생존 우위가 남는다. 성장 이후의 균형을 위해 이 조건의 성공률까지 억지로 같게 만들지는 않았다. 후반/최대 성장에서는 전술 클리어율이 모두 100%로 포화되므로 높은 난도 콘텐츠의 지속적인 도전성은 별도 설계가 필요하다. 모든 장비 조합·유물 최적 선택·실제 모바일 조작·인간 플레이 시간은 이 실험으로 보장하지 않는다.

## 재현

아래 명령은 현재 코드의 결과를 생성한다. balance-before*.json은 조정 전 스냅샷이므로 덮어쓰지 않는다.

```sh
node tools/balance.js --output=docs/balance-after.json
node tools/balance.js --route=elite --output=docs/balance-after-elite.json
node tools/balance.js --gear=none --output=docs/balance-after-no-gear.json
node tools/balance-compare.js
npm test
npm run build
npm run test:browser
```

balance-compare.js는 같은 현재 전투 엔진에 조정 전 클래스 데이터와 현재 데이터를 차례로 적용한다. 이번 변경은 이 데이터로 전후 재현할 수 있다. 향후 전투 규칙 자체가 바뀌면 이 도구의 이전 버전 재현 범위도 재검토해야 한다.

원본 JSON에는 클래스 수치, 강화 단계/비용, 시드 범위, 승리 수, 전체/승리 평균 턴, 승리 시 HP 비율, 물약 사용, 사망 구간, 행동 횟수를 보관한다. 실패가 빨라져 전체 평균 턴이 낮아지는 현상을 화력 향상으로 해석하지 않도록 승리 평균을 별도로 제공한다.
