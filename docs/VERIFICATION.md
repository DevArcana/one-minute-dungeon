test-results/screenshots에 타이틀/전투의 PC·모바일·태블릿·가로 화면, 보스·상점·결과 스크린샷을 생성했다. PC 타이틀·전투·보스와 모바일 타이틀·전투를 직접 열어 이미지와 레이아웃을 확인했다. 모바일 입장 버튼은 하단 고정으로 접근성을 개선했다.

## 전략 비교 (별도 2,400회)
각 클래스/난도/전략 조합에 100개 시드. 체력 위급 시 물약 사용은 두 전략에 공통. 전술 전략은 강공격 방어와 자원 활용을 추가한다.

| 난도 | 전술 전사 | 전술 도적 | 전술 마법사 |
|---|---:|---:|---:|
| 0 | 100% | 100% | 100% |
| 1 | 100% | 90% | 100% |
| 2 | 98% | 32% | 52% |
| 3 | 56% | 0% | 6% |

기본 난도 공격 위주 클리어율은 전사 6%, 도적 1%, 마법사 0%. 높은 난도는 영구 성장 없는 초기 캐릭터 기준이므로 모든 난도가 초기 상태에서 균등하게 클리어되는 것을 목표로 하지 않았다. 전사의 과도한 우세를 줄이기 위해 스킬 방어를 50%로 조정하고 스킬 자동 반격 충전을 제거했다.

## 수정한 문제
BOM으로 인한 번들 구문 오류, 이미지 축소 시 정수 오버로드 문제, 종료 이벤트가 새로운 저장을 덮어쓰는 문제, 중복 장비 구매, 백업 실패 시 원본 덮어쓰기 위험, 모바일 고정 CTA, 보스 연출 매 턴 반복, 잠금 해제 때 불필요한 전체 DOM 갱신을 수정했다.

## 남은 한계
실제 iOS Safari/Android 기기, 화면낭독기 청취, 실제 오디오 청취 테스트는 수행하지 않았다. 3~5분은 설계 목표이며 인간 플레이 시간 실측이 아니다. 숙련 플레이는 더 짧다. 높은 난도 클래스 격차, 장비 성장 후 밸런스는 추가 조정이 필요하다.
보스 1종/일반 아트 2종으로 콘텐츠 다양성은 제한적이다. BGM/펫/퀘스트/보스러시/스토리는 제외했다. Web Locks 미지원 환경에서는 원문 비교로 오래된 저장을 감지하지만 정확히 동시인 쓰기는 완전히 제어하지 못한다. 생성 이미지 중 일부는 완전한 투명 배경이 아니다.

- 한계: 동일 버전/동일 출처의 Web Locks 지원 탭끼리의 쓰기를 직렬화한다. 미지원 환경의 정확히 동시인 쓰기나 구버전 탭처럼 잠금을 사용하지 않는 쓰기는 완전히 보호하지 못한다.
