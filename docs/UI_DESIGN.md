# UI design
## Tokens
배경 #0c1419, 패널 #131f25, 전경 #e9e8dd, 보조 #a2b2b7, 금색 #e5b96e, 청록 #73d5c3, 위험 #eb8277. CSS :root에서 색상/기본 간격/반경을 정의한다. 시스템 한글 sans-serif; 영문 타이틀은 Georgia/Times serif. 외부 폰트 다운로드 없음.

기본 간격 8/12/16/24/32px, 패널 반경 14px, 카드 12px, 버튼 8px. 기본 본문 15px, 설명 12~14px, 장식 영문은 9~11px. 행동 버튼은 터치 영역 48px 이상, 주요 입장 버튼 58px 이상.

## 정보 구조
타이틀: 큰 대표 아트/브랜드 → 클래스 세 장 → 클래스 설명 → 입장/이어하기 → 성장/가방/도감.
전투: 적 이름/HP → 다음 행동 → 큰 적/플레이어 아트 → HP/자원 → 네 행동 → 최근 기록.
PC: 좌측 장비/능력, 중앙 전투, 우측 경로/유물. 1150px 이하 우측을 접고 보조 버튼 제공. 760px 이하 단일 열. 360px 이하는 간격·그림 축소. 가로 높이 500px 이하에서는 전투 아트 높이 축소. safe-area-inset-bottom 적용, 페이지 확대 허용.

## 컴포넌트
HP/마나/적 HP는 수치+progressbar aria 속성으로 표현. 독/화상은 남은 턴 텍스트, 반격은 명시적 상태 태그. 희귀도는 색상만이 아니라 일반/희귀/영웅 문자 라벨. 장착 장비는 금색 테두리와 장착 중 문구.

native dialog: 중앙 배치, 최대 720px/85dvh, 뒤 배경 흐림, sticky 제목/닫기. 브라우저 포커스 트랩 사용, Escape/닫기 지원, 닫힌 후 트리거 포커스 복원. 저장 데이터 문자열은 HTML escape 처리.

## Interaction
hover는 밝기/테두리, active는 2px 이동, disabled는 명도와 native disabled, focus-visible은 청록 3px 윤곽선. 키보드 1~4, Tab, Enter. 모달이 열려 있으면 전투 단축키 차단. 매 렌더에서 대응 버튼 포커스 복원. 중요 화면 전환 시 제목으로 포커스 이동.

공격 이동·피격 플래시·피해 숫자 320~700ms. 타이틀 대표 캐릭터에만 5초 idle. prefers-reduced-motion에서 모든 장식 애니메이션 중지. 전투 상태는 애니메이션 타이머에 의존하지 않는다. 이미지 오류는 캐릭터 이름 대체 요소로 처리한다.
